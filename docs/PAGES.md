# انتشار پیش‌نمایش عمومی سایت

نسخهٔ 4.1.1 انتشار GitHub Pages را برای هر ۳۶ مسیر فارسی، انگلیسی و عربی فعال می‌کند. نسخهٔ 4.1.0 فقط سورس جدید را ثبت کرده بود و صفحهٔ عمومی به‌روزرسانی نشده بود.

- فارسی: https://saeideeshghi.github.io/marpich-sanat-v4/
- انگلیسی: https://saeideeshghi.github.io/marpich-sanat-v4/en/index.html
- عربی: https://saeideeshghi.github.io/marpich-sanat-v4/ar/index.html

## ساخت و بررسی محلی

```powershell
npm ci
npm run check:release
npm run build:pages
npm run preview:pages
```

ساخت اختصاصی در `dist/pages` قرار دارد و آدرس preview شامل `/marpich-sanat-v4/` است. ساخت عادی و بک‌اند همچنان با مسیر ریشه کار می‌کنند. ساخت عادی تمام `dist` را بازسازی می‌کند؛ اگر چند خروجی لازم است، آن را اول اجرا کنید.

نام مخزن از `github-pages.json` و در GitHub Actions از `GITHUB_REPOSITORY` خوانده می‌شود. لینک‌های سه زبان، تغییر زبان، فونت‌های انگلیسی، CSSهای مشتق‌شده و فایل‌های تصویری، پیشوند مخزن را حفظ می‌کنند. استایل‌ها یا تنظیمات ظاهری تغییر نکرده‌اند.

آزمون `build:pages` هر ۳۶ صفحه، manifest و لینک CSS/JS/فونت را در مسیر واقعی انتشار بررسی می‌کند. ابزارهای ویرایش، فایل تنظیمات قابل‌ویرایش و پیش‌نمایش داخلی ابزار طراحی در این خروجی منتشر نمی‌شوند.

## انتشار

گردش‌کار `.github/workflows/pages.yml` پس از تغییر `main` یا اجرای دستی، سورس را بررسی می‌کند، خروجی Pages را می‌سازد و همان خروجی را منتشر می‌کند. باید منتظر موفقیت هر دو مرحلهٔ build و deploy ماند و سپس لینک آنلاین را باز کرد؛ ثبت commit یا tag به‌تنهایی اثبات انتشار سایت نیست.

این سایت عمومی، نمایش فرانت‌اند است؛ سرویس ورود واقعی، ارسال فرم، پیامک و CMS با انتشار Pages ساخته نمی‌شوند.
