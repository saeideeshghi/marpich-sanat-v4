# انتشار 4.1.5 — هماهنگ‌سازی طراحی فارسی و عربی

تاریخ: ۲۰۲۶/۱۱/۱۴. مبنا: نسخهٔ 4.1.4 و شاخهٔ `main`. همان ۱۲ قالب مشترک و ۳۶ مسیر فارسی، انگلیسی و عربی حفظ می‌شوند.

## تغییرات

- طراحی فارسیِ درباره‌ما، تماس و نساجی بر اساس مرجع 4.0.3 بازگردانده شد؛ قالب‌ها و منابع مشترک فقط یک‌بار ویرایش شده‌اند.
- قواعد چیدمان عربی با فارسی یکسان شد. `dir="rtl"` و فونت Peyda حفظ شده‌اند و برچسب ورود کوتاه شده تا در همان اندازهٔ دکمه نمایش داده شود.
- استایل انگلیسی نسخهٔ 4.1.4 حفظ شد؛ URL فونت‌ها و دارایی‌ها اکنون پیشوند مسیر پایهٔ Pages را هم می‌گیرند.
- پیش‌نمایش و خروجی ابزار سفارشی‌سازی مسیر زبان را رعایت می‌کنند و خروجی‌های Pages و بک‌اند بررسی می‌شوند.

## بررسی‌ها

- `npm run check:release` موفق؛ شامل بررسی ساختار، ترجمه‌ها، امنیت، SVG، دارایی‌ها، کارایی و قالب‌بندی.
- `npm run build:pages` موفق؛ ۳۶ ورودی و ۱۳۲ لینک CSS با مسیر `/marpich-sanat-v4/` ساخته شدند.
- `npm run build:backend` موفق؛ ۳۶ نمای صفحه، manifestهای CSS/JS مرتب و بدون ابزار عمومی ویرایشگر.
- مقایسهٔ بصری فارسی و عربی در صفحه‌های اصلی، محصولات، درباره‌ما، تماس و نساجی در عرض دسکتاپ ۱۴۴۰ پیکسل انجام شد. تفاوت طبیعی در شکست متن عربی می‌تواند ارتفاع بعضی کارت‌ها را تغییر دهد.

## انتشار

سورس این نسخه در شاخهٔ `release/v4.1.5` و تگ `v4.1.5` قرار می‌گیرد. این شاخه و تگ workflow انتشار عمومی Pages را فعال نمی‌کنند؛ workflow موجود فقط روی push به `main` اجرا می‌شود.
