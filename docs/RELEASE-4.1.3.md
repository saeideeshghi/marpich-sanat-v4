# تحویل نسخهٔ 4.1.3 — اصلاح چیدمان سه‌زبانه

تاریخ: ۲۰۲۶/۱۰/۲۹. این نسخه ادامهٔ همان سایت با ۱۲ قالب مشترک و ۳۶ مسیر فارسی، انگلیسی و عربی است.

## اصلاح‌های انجام‌شده

- علت جابه‌جایی خط منو و ناپدیدشدن پترن انگلیسی در خروجی نهایی، کوتاه‌شدن `translateX` به `translate` هنگام فشرده‌سازی بود. تبدیل CSS اکنون هر دو شکل را همراه `translate3d`، `calc` و متغیر افقی Tailwind پوشش می‌دهد.
- پترن‌ها و کنترل بازگشت به بالا در مرکز کادر می‌مانند. مرکز خط منوی انگلیسی از مختصات منطقی استفاده می‌کند؛ طول خط از طول لینک بیشتر نمی‌شود.
- محل فلش select، مبدأ حرکت دسته‌بندی، فلش‌های فرم و کارت و ترتیب ستون‌های انگلیسی اصلاح شد. خوانایی متن، عدد، ایمیل و تلفن مستقل از ترتیب ستون‌ها حفظ می‌شود.
- نوشتهٔ فارسیِ لوگو در انگلیسی و عربی با لوگوی بین‌المللی برداری جایگزین شد: همان نشان اصلی، `MPS` و `MARPICH SANAT` با مسیرهای Montserrat. فایل اصلی فارسی دست‌نخورده است.

## حفظ ظاهر و سرعت

هش CSSهای متصل به هر ۱۲ صفحهٔ فارسی با خروجی 4.1.2 مقایسه شد و یکسان بود. تنظیمات طراحی، عکس‌ها، فونت‌ها و داده‌های پترن فارسی تغییر نکردند. تمام ۵۲ فایل JavaScript خروجی Pages همان نام هش‌شده و حجم نسخهٔ قبل را دارند؛ وابستگی یا حلقهٔ اجرایی تازه‌ای اضافه نشده است.

تغییر جهت و جایگزینی لوگو هنگام ساخت انجام می‌شود. لوگوی بین‌المللی حدود ۱۲ کیلوبایت است، در برابر حدود ۴۴ کیلوبایت فایل اصلی؛ برای حروف آن فونتی دانلود نمی‌شود. پترن‌ها همان پخش‌کنندهٔ بومی SVG، بارگذاری تدریجی فوتر، توقف خارج از دید و پشتیبانی کاهش حرکت را حفظ می‌کنند. این‌ها شواهد اندازه و ساختارند؛ زمان بارگذاری واقعی به سرور، شبکه و دستگاه هم وابسته است.

## ادامهٔ توسعه

قالب و دادهٔ مشترک را یک بار ویرایش کنید؛ فایل‌های `en/*.html` و `ar/*.html` صرفاً ورودی ساخت‌اند. CSS و تنظیمات فارسی را برای اصلاح انگلیسی تغییر ندهید. قواعد چیدمان بین‌المللی در `src/css/locales/en-fonts.css` و تبدیل خروجی در `build/locale-output.js` است. راهنمای جزئی‌تر در [LOCALIZATION.md](LOCALIZATION.md) قرار دارد.

فایل‌های `dist`، `node_modules` و `.cache` منبع توسعه نیستند. برای اجرای پروژه از پوشهٔ `Project` بستهٔ تحویل، کنار `package.json`، `npm ci` و سپس `npm run dev` را اجرا کنید. برای تحویل بک‌اند `npm run build:backend` خروجی را در `dist/backend` می‌سازد.

اتصال واقعی فرم‌ها، ورود، پیامک و لینک‌های نمونه همان موارد باز قبلی پروژه‌اند؛ این اصلاح ظاهری سرویس بک‌اند تازه‌ای ایجاد نمی‌کند.
