# انتشار 4.1.4 — اصلاحات بازبینی سه‌زبانه

تاریخ: ۲۰۲۶/۱۱/۰۳. مبنا: `main` و `v4.1.3`. این نسخه همان ۱۲ قالب مشترک و ۳۶ مسیر فارسی، انگلیسی و عربی را ادامه می‌دهد.

## تغییرات

- لوگوی انگلیسی از مسیرهای اصلی نشان و MPS ساخته شده و فقط شعار زیر آن ترجمه شده است.
- چیدمان هدر و تصویر اصلی انگلیسی، فاصله‌ها، دکمه‌ها، خوانایی متن، اندازهٔ تیترها و هم‌ترازی کارت‌ها اصلاح شده‌اند.
- عنوان‌های بلند انگلیسی کوتاه شده‌اند؛ متن‌ها فاصله‌گذاری کشیده ندارند و توضیحات با وزن معمولی نمایش داده می‌شوند.
- پترن‌های داخلی، فلش‌ها، گرادیان‌ها و تصاویر جهت‌دار انگلیسی اصلاح شده‌اند. مرکز پترن پس از معکوس‌کردن و فشرده‌سازی حفظ می‌شود.
- دسته‌بندی انگلیسی از چپ باز می‌شود؛ تصویر در قاب مستقل معکوس می‌شود تا مختصات حرکت تغییر نکند. زمان‌بندی و رفتار فارسی و عربی حفظ شده‌اند.
- تگ‌های محصول انگلیسی مطابق نمونهٔ یک‌به‌دو و تگ‌های عربی در سه ردیف قرار گرفته‌اند.
- ایران به نشانی‌های انگلیسی و عربی اضافه شده؛ هم‌پوشانی اطلاعات تماس رفع شده است.
- عرض ورود عربی، متن هدر و مرکزچین دکمه‌های آن اصلاح شده‌اند.
- یک مرحلهٔ فرضی تاریخچه از قالب مشترک دربارهٔ ما حذف شده است.

## بررسی‌ها و حفظ نسخهٔ قبلی

- ساخت عادی، بررسی خروجی و ساخت بک‌اند موفق؛ خروجی بک‌اند ۳۶ صفحه دارد.
- بررسی پروژه، ترجمه، امنیت، SVG، دارایی‌ها، کارایی و قالب‌بندی موفق است.
- مرورگر بدون افزونه: ۱۴۴ حالت (۳۶ مسیر در عرض‌های ۱۵۰۰، ۱۱۸۰، ۷۶۸ و ۳۹۰)، همراه تعامل‌های جست‌وجو، دسته‌بندی، اعتبارسنجی فایل، ورود موبایل و تغییر زبان.
- ۶۶ بررسی اختصاصی مرکز پترن و بررسی واقعی قاب تصویر و جهت بازشدن دسته‌بندی‌ها موفق بوده‌اند.
- CSS متصل به تمام ۱۲ صفحهٔ فارسی با بکاپ 4.1.3 یکسان است؛ فونت‌ها، تصاویر اصلی و تنظیمات فارسی تغییر نکرده‌اند.
- فایل بکاپ 4.1.3 با SHA-256 ذخیره‌شده مطابقت دارد و حفظ شده است.

جزئیات هر درخواست و شاهد بررسی در [گزارش بازبینی تلگرام](TELEGRAM-REVIEW-2026-11.md) است. اتصال واقعی فرم‌ها، ورود و پیامک همچنان در محدودهٔ کار بک‌اند آینده است.

## اجرا و تحویل

برای توسعه `npm ci` و `npm run dev` را اجرا کنید. برای اتصال به بک‌اند از `npm run build:backend` و manifest همان مسیر استفاده کنید. فایل‌های `en` و `ar` ورودی ساخت هستند؛ قالب‌های مشترک را یک بار ویرایش کنید.

انتشار گیت‌هاب با برچسب `v4.1.4` و بستهٔ شامل سورس، خروجی بک‌اند و گزارش‌ها انجام می‌شود. روند GitHub Pages همان روند از پیش موجود مخزن است.
