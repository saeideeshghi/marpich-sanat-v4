# تماس، لبهٔ تصاویر و جای پترن · ۱۰ اکتبر ۲۰۲۶

این اصلاحات روی آخرین نسخهٔ پروژه اعمال شده‌اند. تغییرات تماس، گالری و حوزه‌های تخصصی در فایل همان صفحه قرار دارند؛ تغییر مشترک پترن فقط به لایهٔ تزئینی مربوط است.

## تماس

`::before` سمت راست عنوان همکاری است و تغییر نکرده؛ `::after` سمت چپ با `rotate(180deg)` معکوس می‌شود. رنگ و طول خطوط همان مقدار قبلی است.

`padding-bottom` در `.contact-main` صفر است، بنابراین آخرین باکس مزایا بدون فاصله به فوتر وصل می‌شود. Padding داخل مزایا و اندازهٔ خود فوتر حفظ شده‌اند. در دکمهٔ واتساپ، ابتدا `span` متن و سپس `img` قرار دارد؛ در RTL آیکون در سمت چپ متن، بعد از آن در ترتیب خواندن، نمایش داده می‌شود. شماره‌ها و لینک‌ها تغییر نکرده‌اند.

## گالری و حوزه‌های تخصصی

گالری در قاب ثابت با `overflow: hidden` نمایش داده می‌شود؛ `transform-origin: center bottom` لبهٔ پایین را هنگام Zoom ثابت نگه می‌دارد. بزرگ‌نمایی همچنان ۱٫۰۶ و زمان عادی ۴۲۰ms است. اندازهٔ بخش و متن قبلی حفظ شده‌اند.

SVG فعلی گالری خودش سایه و حاشیهٔ خالی بالا و پایین دارد. `prepareGalleryPhoto()` فقط برای همین خروجی شناخته‌شده، ViewBox را به مستطیل واقعی عکس محدود و Filter سایه را حذف می‌کند. این کار روی کپی موقت `.cache/static-public` در اجرا و Build انجام می‌شود؛ `assets/images/about/gallery.svg` و تصویر جاسازی‌شده در آن تغییر نمی‌کنند. SVG سفارشی با مشخصات دیگر بدون تغییر عبور می‌کند.

در کارت باز حوزه‌های تخصصی، `border-top` پنل توضیحات حذف شده است. تصویر یک پیکسل اضافه قاب را می‌پوشاند تا گردشدن اندازه‌های نسبی خطی بین عکس و قاب نسازد. گردی کارت بیرونی، رنگ، فاصله‌ها و بازشدن فقط یک کارت حفظ شده‌اند.

## پترن

در بازهٔ ۶۷۵–۱۱۸۰px، مرکز قاب پترن هدر با مرکز زمینهٔ تیره هم‌راستا می‌شود. اندازه‌گیری از ارتفاع واقعی لایه، شامل `--site-pattern-crop-height` در هیروهای دارای فرم یا کارت، انجام می‌شود؛ متن و فرم جابه‌جا نمی‌شوند. مقدار Y برابر ۷٫۱٪ مرجع وسط‌چینی است و تغییر Y در کاستومایزر همچنان جابه‌جایی مستقل ایجاد می‌کند. بیرون این بازه، جای قبلی حفظ شده است.

نوک دو خط کوتاه افقی، دوم و چهارم از بالا، در امتداد مماس به X برابر منفی ۹ رسیده‌اند. بقیهٔ منحنی، ضخامت و رنگ تغییر نکرده‌اند. این اصلاح برای طرح‌های افقی هدر و فوتر اعمال شده؛ طرح عمودی فوتر موبایل دست‌نخورده است.

دامنهٔ ۳۱، دورهٔ موج ۵ ثانیه، کشش عمودی ۷۰٪، دورهٔ ضربان ۹ ثانیه، عرض فوتر ۱۰۱٫۷٪، وضوح هدر ۳۵٪ و فوتر ۳۲٪ حفظ شده‌اند. حلقهٔ بومی SVG همچنان شروع فوری، سرعت Linear و تکرار بی‌نهایت دارد.

## اعمال و اتصال Backend

فایل‌های بسته را در ریشهٔ پروژه، کنار `package.json` جایگزین کنید و تصاویر و فونت‌های فعلی را نگه دارید. HTML خام به پردازش Vite نیاز دارد؛ `npm run dev` برای اجرا و `npm run build:pages` برای خروجی GitHub Pages است.

این اصلاحات endpoint یا قرارداد دادهٔ جدیدی ندارند. CMS باید ترتیب متن و آیکون لینک‌های واتساپ، نام کلاس‌ها، ساختار گالری و کارت‌های تخصصی را حفظ کند. راهنمای کل پروژه در `ARCHITECTURE.md`، پیاده‌سازی Backend در `BACKEND-INTEGRATION.md` و شرح حلقهٔ پترن در `PATTERN-ANIMATION.md` است.

## بررسی تحویل

هر ۱۲ صفحه در ۱۶ عرض از ۳۲۰ تا ۱۹۲۰px با نسخهٔ قبلی مقایسه شدند. اندازه و چیدمان متن‌ها، دکمه‌ها، فرم‌ها و کارت‌ها حفظ شده‌اند؛ تنها کاهش فاصلهٔ خواسته‌شدهٔ تماس، جای فوتر همان صفحه را تغییر می‌دهد. اسکرول افقی جدید ایجاد نشده است.

Hover گالری در شش عرض، هر پنج کارت تخصصی در چهار عرض و اتصال مزایا به فوتر و ترتیب واتساپ در ده عرض بررسی شدند. وسط‌چینی هدر در تمام صفحات داخلی، تغییر Y کاستومایزر، اتصال ابتدا و انتهای انیمیشن بومی SVG و حفظ پترن عمودی موبایل نیز بررسی شدند. تمام ۲۶۴ فایل تصویر، آیکون و فونت موجود با نسخهٔ قبل یکسان‌اند.

`npm run check`، `npm run format:check` و `npm run build:pages` موفق بودند؛ خروجی Pages برای هر ۱۴ ورودی بررسی شده است. این بسته شامل سورس و راهنماهاست؛ تصاویر و فونت‌های اصلی را در مسیرهای قبلی نگه دارید.
