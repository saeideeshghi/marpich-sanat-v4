# بررسی امنیت، کارایی و کیفیت نسخهٔ 4.0.2

بررسی روی سورس شاخهٔ `main`، هر ۱۲ صفحه، خروجی Backend و خروجی GitHub Pages انجام شد. مرجع مقایسهٔ سرعت، Commit `39bf81e` با نسخهٔ 4.0.1 است. فایل‌های اصلی عکس‌ها و فونت‌ها، تنظیمات انیمیشن محصولات و تنظیمات پترن‌ها حفظ شدند.

## اصلاحات

- فونت آیکون‌ها در خروجی تولید از ۱۳۹٬۰۰۰ به ۳٬۳۰۰ بایت رسید؛ CSS مربوط به نمادهای استفاده‌نشده نیز حذف شد. حالت توسعه مجموعهٔ کامل را نگه می‌دارد تا افزودن آیکون با ویرایش زنده کار کند. آیکون‌های جدید باید در HTML، JavaScript یا داده‌های سورس با نام کامل ثبت شوند. مجوز Font Awesome همراه فونت تحویلی قرار می‌گیرد. ابزار [subset-font](https://github.com/papandreou/subset-font) فقط هنگام ساخت اجرا می‌شود.
- عکس‌های جاسازی‌شده در SVG نسخه‌های WebP متناسب با اندازهٔ نمایش دارند. نسخهٔ تحویلی بدون افت پیکسل است؛ نسخهٔ برداری بزرگ و فایل اصلی موجود می‌مانند. شکل‌های کاملاً برداری، تصاویر خارجی و نمودار فنی از این تبدیل خارج‌اند. انتخاب نسخه‌های عکس اصلی و کارت‌های عکاسی نیز دقیق‌تر شد.
- اندازهٔ طبیعی تصاویر در HTML ثبت می‌شود تا قبل از دریافت فایل، نسبت ابعاد مشخص باشد. اندازه‌های صریحِ نویسنده حفظ می‌شوند. هنگام انتخاب تصویر سفارشی، `srcset` و اندازهٔ تولیدشدهٔ تصویر قبلی کنار می‌روند؛ بازگشت به تصویر اصلی، اطلاعات قبلی را بازیابی می‌کند.
- ساخت سایت پیش از کپی فایل عمومی، تنظیمات خصوصی، کلیدها، پوشه‌های حساس و لینک‌های فایل‌سیستم را رد می‌کند. SVG دارای اسکریپت، رویداد اجرایی، HTML جاسازی‌شده، DTD یا لینک اجراییِ کدگذاری‌شده نیز رد می‌شود. بررسی کلیدهای شناخته‌شده شامل SVG و فایل‌های متنی دارایی‌هاست؛ فقط نام فایل نامعتبر گزارش می‌شود.
- هر Build پوشهٔ موقتِ متعلق به همان پردازش را در پایان پاک می‌کند. مسیر پاک‌سازی محدود به کش مشخصِ همان پردازش است. بررسی فایل‌ها و SVG نیز نسخهٔ موقت خود را پاک می‌کند. سه نشانگر `.gitkeep` در پوشه‌های پرشده حذف شدند؛ تصاویر اصلی و پشتیبان‌ها حفظ شدند.
- پیش‌نمایش با حالت چندصفحه‌ای Vite اجرا می‌شود. مسیر ناموجود، فایل خصوصی و endpoint ناموجود پاسخ ۴۰۴ می‌گیرند؛ صفحهٔ اصلی به‌عنوان پاسخ موفق جای آن‌ها نمایش داده نمی‌شود. `robots.txt` معتبر اضافه شد.
- Paste طبیعی مرورگر مسدود نمی‌شود؛ کدهای فارسی و عربی برای OTP شش‌رقمی تقسیم می‌شوند. اطلاعات Paste پس از پایان عملیات پاک می‌شوند. نام قابل‌خواندن کنترل زبان و نقش امتیاز ستاره‌ای اصلاح شدند؛ رنگ چند متن کوچک برای خوانایی در همان طیف تیره‌تر شد.
- جزئیات کارت‌های تخصص در مرورگر دارای JavaScript از ابتدا بسته‌اند و پس از دریافت اسکریپت جابه‌جا نمی‌شوند. محتوای بدون JavaScript همچنان خواندنی است. این شرط از [media feature استاندارد scripting](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/At-rules/@media/scripting) استفاده می‌کند؛ مرورگر قدیمی رفتار قبلی را حفظ می‌کند.

آزمون عمومیِ امنیت شامل escaping متن، URL اجرایی، دادهٔ SVG نامعتبر، نگهداری‌نکردن اطلاعات ورود در storage، میزبان و Origin محلی ابزار تنظیمات، توکن ویرایش، تعارض نسخه، ورودی بیش‌ازحد و UTF-8 فارسی است. آزمون‌های تازه همچنین کپی فایل خصوصی از `public`، مسیر لینک‌شده، SVG فعال/کدگذاری‌شده و محدودیت مسیر پاک‌سازی را بررسی می‌کنند.

خروجی GitHub Pages نیز در ۲۴ ترکیب صفحه/عرض جداگانه بررسی شد: منابع با پیشوند مخزن، آیکون‌های تماس، نبود خطای کنسول و تصویر مفقود، پاسخ ۴۰۴ مسیر خصوصی، مسدودشدن اسکریپت inline با CSP، غیرفعال‌بودن ورود بدون Backend و نبود مسیر نوشتن تنظیمات تأیید شدند. در سرور توسعه، فونت کامل آیکون‌ها و CSS تولیدی بارگذاری شدند؛ خواندن تنظیمات از میزبان محلی مجاز و درخواست با Origin، Host یا توکن نامعتبر رد شد. این بررسی تنظیمات کاربر را بازنویسی نکرد.

## سنجش سرعت

Lighthouse 13.5.0 با Chrome 155 روی preview محلی اجرا شد. هر ۱۲ صفحه در دو پروفایل اندازه‌گیری شدند: موبایل ۴۱۲×۸۲۳ با DPR=1.75، شبکهٔ شبیه‌سازی‌شدهٔ ۱٫۶Mbps و CPU چهار برابر کندتر؛ دسکتاپ ۱۳۵۰×۹۴۰ با preset دسکتاپ. اندازه‌گیری‌ها آزمایشگاهی‌اند و دادهٔ کاربران واقعی یا تضمین سرعت اینترنت محسوب نمی‌شوند. روش و وزن امتیازها در [مرجع Lighthouse](https://developer.chrome.com/docs/lighthouse/performance/performance-scoring) آمده است.

نتیجهٔ نهایی و مرجع پیش از اصلاح در جدول‌های زیر ثبت شده‌اند.

امتیاز Best Practices و SEO در هر ۲۴ اجرا برابر ۱۰۰ است. Accessibility موبایل در همهٔ صفحات ۱۰۰ و دسکتاپ ۹۶ تا ۱۰۰ است. TBT در ۲۳ اجرا صفر و در حوزه‌های تخصصی موبایل ۳۱٫۵ms است. هر عدد حاصل یک اجرای مستقل در هر مرحله است؛ اختلاف کوچک، مانند هواساز دسکتاپ، می‌تواند تحت تأثیر نوسان آزمایش باشد.

صفحات دارای عکس‌های بزرگ، به‌ویژه پروژه‌ها، در شبکهٔ کند هنوز LCP بالاتر از هدف ۲٫۵ ثانیه دارند. نسخه‌های کوچک‌تر تصاویر فراهم شده‌اند، ولی انتخاب مرورگر به ابعاد نمایش و DPR بستگی دارد؛ نسخهٔ اصلی و کیفیت مورد تأیید حفظ شده است. عکس‌های فنی و تصویر متحرک محصولات عمداً با فشرده‌سازی مخرب بازنویسی نشدند. فونت‌های فارسی و CSS اولیه نیز همچنان در مسیر نمایش اولیه‌اند. صنعت نساجی دسکتاپ هنوز CLS=0.120 دارد و گزارش جابه‌جایی را به هندسهٔ متن هنگام جایگزینی فونت مربوط می‌کند؛ شکل نهایی صفحه و سیستم تایپوگرافی حفظ شده‌اند. بهبودهای ثبت‌شده به معنی رسیدن همهٔ صفحات به امتیاز ۱۰۰ یا حذف همهٔ هزینه‌های بارگذاری نیستند.

## حدود بررسی

- این مخزن فرانت‌اند و قرارداد اتصال است. امنیت واقعی نشست، cookie، CSRF سمت سرور، محدودیت تلاش ورود، بررسی محتوای فایل و پایگاه داده باید پس از اتصال Backend نیز آزمایش شود. آزمون‌های مرورگرِ ورود از پاسخ HTTP کنترل‌شده استفاده می‌کنند.
- ۷۵ لینک نمایشی `#` و سرویس‌های اتصال‌نیافتهٔ مستندشده همچنان متعلق به مرحلهٔ محتوا/CMS هستند؛ موفقیت صوری برای آن‌ها نمایش داده نمی‌شود.
- در GitHub Pages، CSP در HTML اعمال می‌شود؛ جلوگیری از iframe به هدر واقعی سرور نیاز دارد. خروجی Backend هدرهای لازم را در قرارداد تحویل دارد.
- گزارش کنتراست خودکار برای چند لینک سفیدِ هدر شفاف، پس‌زمینهٔ روشنِ ancestor را لحاظ می‌کند. نمایش واقعی هدر روی زمینهٔ سرمه‌ای به‌صورت بصری بررسی شده است؛ امتیاز خودکار با این محدودیت ثبت می‌شود.
- ابزار اجرا حذف بازگشتی کش قدیمی را حتی با مسیر صریح با پیام `blocked by policy` رد کرد. آن پوشه‌های محلی در Git نادیده گرفته می‌شوند؛ پاک‌سازی خودکارِ ساخت‌های جدید مستقل از این کار آزمایش شده است.

گزارش‌های خام مرورگر و Lighthouse در `.cache` نگه داشته می‌شوند و در مخزن یا سایت عمومی منتشر نمی‌شوند. تنظیمات اصلی انیمیشن و پترن با سورس قبلی تطبیق داده شدند؛ انتشار نسخهٔ 4.0.2 در همان مخزن `saeideeshghi/marpich-sanat-v4` انجام می‌شود.
