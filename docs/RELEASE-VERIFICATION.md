# گزارش بررسی نهایی · ۱۲ اکتبر ۲۰۲۶

## اصلاحات جدید طبق فایل ارسالی کاربر

طبق اصلاح نهایی کاربر، قانون جداگانهٔ margin-bottom حذف شد و خود باکس معرفی محصول از عرض ۱۱۸۰px با هم‌پوشانی ۲۱۰px به بالا منتقل می‌شود (`translateY(-210px)`). جبران فاصله در همان مکانیزم مشترک انجام می‌شود تا فاصلهٔ بخش بعدی حفظ شود؛ در ۱۱۷۹px هم‌پوشانی قبلی ۱۷۶px و در موبایل ۱۴۰px باقی است. باکس پروژه از عرض ۱۱۸۱px، با حفظ مقدار هم‌پوشانی محاسبه‌شدهٔ هدر، پانزده پیکسل بالاتر قرار می‌گیرد (`margin-top: calc(-1 * var(--hero-summary-overlap, 144px) - 15px)`). تنظیمات `src/data/product-motion/config.json` مطابق فایل ارسالی کاربر جایگزین شده‌اند: زمان باز شدن ۱۳۶۰ms با تأخیر ۳۴۵ms و زمان بسته شدن ۹۵۰ms. جدول زمان‌های سریع‌تر پایین، مربوط به تنظیمات قبلی است و معیار زمان انیمیشن فعلی نیست.

CSS همچنان در head بارگذاری می‌شود. در خروجی تولیدی، پترن ثابت صفحه و ماژول/دادهٔ پترن هدر زودتر دریافت می‌شوند؛ ماژول فوتر زودبارگذاری نمی‌شود. تصویر اصلی خانه `fetchpriority="high"` دارد؛ تصویر اصلی منتظر آماده‌شدن انیمیشن پترن نمی‌ماند. تصاویر پایین صفحه همچنان تنبل و با decode ناهمگام بارگذاری می‌شوند.

این گزارش مربوط به فرانت‌اند موجود و خروجی تحویل بک‌اند است. سرویس بک‌اند و هاست نهایی هنوز به این پروژه متصل نیستند. تست مرورگر با Chrome در context جدا، بدون افزونه، روی localhost و با کش شبکهٔ غیرفعال انجام شد. دامنهٔ واقعی یا تست نفوذ روی سرویس خارجی بررسی نشده است.

## بارگذاری و حرکت

اندازه‌گیری قبل/بعد روی همان سرور توسعه و viewport برابر ۱۴۴۰ × ۱۰۰۰ انجام شد. حجم درخواست‌های اولین نمایش از Resource Timing مرورگر ثبت شد؛ دانلودهای تنبلِ خارج از محدودهٔ اولین نمایش جزو این اعداد نیستند.

| صفحه         | دادهٔ دانلودشده قبل | پس از بهینه‌سازی |     کاهش |
| ------------ | ------------------: | ---------------: | -------: |
| جزئیات محصول |      ۴٬۸۵۵٬۴۶۵ بایت |   ۲٬۵۰۸٬۰۱۶ بایت | حدود ۴۸٪ |
| محصولات      |      ۸٬۹۱۰٬۹۳۴ بایت |   ۵٬۱۹۵٬۸۰۴ بایت | حدود ۴۲٪ |
| درباره ما    |     ۱۹٬۷۸۲٬۱۵۶ بایت |   ۶٬۴۵۵٬۹۶۴ بایت | حدود ۶۷٪ |

آزمون خروجی تولیدی پس از بهبود حرکتِ لایه‌های موقت:

| viewport    | باز شدن کامل |   برگشت کامل | بیشترین فاصلهٔ فریم مشاهده‌شده |
| ----------- | -----------: | -----------: | -----------------------------: |
| ۱۵۰۰ × ۱۰۰۰ | ۴۴۸ تا ۴۹۷ms | ۳۶۸ تا ۳۸۶ms |                    ۵۰ تا ۱۳۳ms |
| ۳۹۰ × ۱۰۰۰  | ۳۷۷ تا ۳۸۱ms | ۴۱۹ تا ۴۲۲ms |                      حدود ۱۷ms |

این بازه‌ها نتایج دو اجرای محلی‌اند، نه تضمین زمان هاست یا ۶۰fps روی تمام دستگاه‌ها؛ در اجرای آخر دسکتاپ یک وقفهٔ فریمی ۱۳۳ms نیز مشاهده شد. ارتفاع مرحله در دسکتاپ `300 → 632px` و در موبایل `389.4375 → 1032.6875px` ثبت شد؛ ارتفاع لحظهٔ تحویل با ارتفاع نهایی یکسان بود. حالت reduced motion نیز مستقل بررسی شد.

## بررسی‌های انجام‌شده

| بررسی                       | نتیجه و پوشش                                                                                                                                                    |
| --------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `npm ci`                    | نصب دوباره از lockfile موفق؛ سرورهای دارای فایل باینری قفل‌شده در ویندوز ابتدا بسته شوند                                                                        |
| `npm run check`             | کنترل‌های ساختار، اجزای مشترک، طراحی، داده، ابزارها و انتشار عبور کردند                                                                                         |
| `npm run format:check`      | قالب فایل‌های قابل‌بررسی با Prettier یکدست شد                                                                                                                   |
| `npm run check:assets`      | هر ۱۷۳ ارجاع تصویر/فونت موجود است؛ لینک دو فایل دانلودِ ناموجود به hook بک‌اند تبدیل شد                                                                         |
| `npm run check:performance` | تمام تنظیمات/مسیرهای پترن یکسان؛ پیکسل قابل‌نمایش و آلفای تصویر آزمایشی حفظ شدند؛ هندسهٔ transform از هر دو لبه صحیح است                                        |
| `npm run check:security`    | URL و HTML تزریقی، SVG ناقص/بیش‌ازحد، Host و Origin جعلی، کلاینت غیرمحلی، توکن نامعتبر، حجم درخواست و UTF-8 تکه‌تکه بررسی شدند                                  |
| `check-svg.js`              | تمام ۳۲۳ مسیر SVG موجود معتبر بودند                                                                                                                             |
| `npm audit`                 | هیچ آسیب‌پذیری شناخته‌شده‌ای گزارش نشد؛ وابستگی‌های جدید نیز پس از نصب بررسی شدند                                                                               |
| `npm run build:pages`       | ۱۴ ورودی با base مخزن و لینک CSS، فونت و importهای JS صحیح ساخته شدند                                                                                           |
| `npm run build:backend`     | ۱۲ صفحه، ترتیب CSS/JS، manifest تصاویر و هدرهای امنیتی؛ بدون انتشار ابزار طراحی یا تنظیمات قابل‌ویرایش                                                          |
| `check-browser.js`          | ۱۲ صفحه در دو viewport (۲۴ ترکیب)، بدون هشدار/خطای کنسول، تصویر اولیهٔ مفقود یا overflow افقی                                                                   |
| ویژگی‌های قبلی              | لینک روی کل کارت، وسط‌چینی CTA، فاصله در مرز ۱۱۸۰/۱۱۷۹، فیلتر شفاف، زیرخط هاور و بازگشت گرید عبور کردند                                                         |
| قرارداد Auth                | بدون CSRF هیچ درخواست فرستاده نشد؛ با توکن تست، POST هم‌دامنه و پاسخ JSON مصنوعی واقعاً از مسیر fetch عبور کرد و موفقیت اعلام شد؛ این تست سرویس ورود واقعی نیست |

هدر CSP روی پاسخ‌های preview مخصوص بک‌اند اعمال و در آزمون ۲۴ صفحه بررسی شد. در سرور واقعی هم باید همین هدرها نصب شوند. فایل‌های auth، فرم‌ها، آپلود، URLهای داده، renderer اجزا، تنظیمات/مقدارهای CSS، ابزار ویرایش و اسکریپت‌های ساخت/انتشار بررسی شدند؛ تضمین نبود تمام آسیب‌پذیری‌های ممکن یا امنیت سرور هنوز ساخته‌نشده ارائه نمی‌شود.

## خطاهای گزارش‌شده و موارد تحویل

پیش‌بارگذاری ثابت فونت حذف شد و هشدار آن در مرورگر آزمایشی مشاهده نشد. فایل `jquery-3.4.1.min.js` در سورس یا وابستگی‌های سایت وجود ندارد و خطای مسیر گزارش‌شده در اجرای بدون افزونه تکرار نشد؛ کاربر نیز فایل را در پروژه پیدا نکرد. validator پترن اکنون نمونهٔ `tc0.2...` را پیش از ذخیره رد می‌کند. منبع بیرون از این سورس بدون URL کامل فایل قابل انتساب نیست.

دانلود مدارک واقعی، URLهای اختصاصی CMS (از جمله ۷۵ placeholder موجود)، ارسال فرم، SMS/OTP و اعتبارسنجی/مجوزهای سرور هنوز باید توسط بک‌اند پیاده‌سازی شوند. نقشهٔ فایل‌ها، تنظیمات امنیتی، قرارداد رویدادها و روش اتصال در [BACKEND-RELEASE.md](BACKEND-RELEASE.md) آمده است؛ خروجی نهایی در `dist/backend` قرار دارد.

منابع فنی: [دستور مسیر SVG](https://www.w3.org/TR/SVG/paths.html#PathDataBNF)، [WebP در sharp](https://sharp.pixelplumbing.com/api-output/#webp)، [WOFF2](https://github.com/fontello/wawoff2)، [پیکربندی Vite](https://vite.dev/config/)، [هدر CSP](https://developer.mozilla.org/en-US/docs/Web/HTTP/Reference/Headers/Content-Security-Policy).
