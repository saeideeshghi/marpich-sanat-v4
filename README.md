# مارپیچ صنعت · راهنمای شروع

نسخهٔ 4.1.2 همان سایت موجود با ۱۲ قالب مشترک و سه زبان فارسی، انگلیسی و عربی است؛ در مجموع ۳۶ مسیر مستقل دارد. ظاهر و تنظیمات فارسی حفظ شده‌اند. فناوری‌ها: Vite، Tailwind CSS، HTML، CSS و JavaScript با ES Modules.

راهنمای آفلاین این نسخه: [docs/implementation-guide.html](docs/implementation-guide.html). جزئیات قراردادهای بک‌اند و نقشهٔ ۱۲ قالب اصلی در [راهنمای تحویل قبلی](docs/backend-handoff.html) باقی مانده‌اند؛ برای تغییرات سه‌زبانه، [LOCALIZATION.md](docs/LOCALIZATION.md) را بخوانید. خود سایت باید با Vite اجرا شود.

## نصب و اجرا

ترمینال را در ریشهٔ نسخهٔ استخراج‌شده، کنار `package.json`، باز کنید. Node.js حداقل 22.12.0 و npm لازم است:

```powershell
npm ci
npm run dev
```

نشانی پیش‌فرض توسعه `http://127.0.0.1:5173/` است. HTML خام شامل دستورهای ترکیب کامپوننت و CSS پردازش‌نشده است؛ دوبار کلیک روی صفحات جایگزین اجرای Vite نیست.

```powershell
npm run check:release
npm run build
npm run check:build
npm run preview
```

خروجی عادی در `dist` شامل ۳۶ صفحه و دو ابزار طراحی است. برای خروجی مناسب اتصال به بک‌اند:

```powershell
npm run build:backend
npm run preview:backend
```

خروجی بک‌اند در `dist/backend` شامل ۳۶ صفحه، manifest، `page-assets.json` و `security-headers.json` است؛ ابزارهای طراحی عمومی نمی‌شوند. `npm run build` کل `dist` و `build:backend` زیرپوشهٔ خودش را بازسازی می‌کند؛ خروجی تولیدی را ویرایش نکنید. اگر هر دو خروجی را می‌خواهید، ساخت عادی را نخست اجرا کنید.

## ویرایش و تنظیمات

- صفحات ریشه، `src/components` و `src/data/pages` محتوای سایت را نگه می‌دارند. همهٔ محتوا در JSON نیست.
- `src/js/pages` نقطه‌های ورود و `src/js/main.js` رفتارهای مشترک هستند. `build/pages.js` فهرست مسیرهای واقعی را تعریف می‌کند.
- `src/css` استایل‌های دستی و تنظیمات ذخیره‌شده را دارد. `build` کد ضروری ساخت است؛ آن را با خروجی `dist` اشتباه نگیرید.
- `assets` و `public` هر دو لازم‌اند. اولویت فایل هم‌مسیر با `public` است. تصاویر SVG ممکن است عکس جاسازی‌شده داشته باشند و نسخه‌های PNG یا فایل‌های راهنمای جایگزینی لزوماً زائد نیستند.
- `npm run customize` یا `CUSTOMIZE.cmd` ابزار ویرایش ظاهر را اجرا می‌کند. `CUSTOMIZER.md` راهنمای دقیق آن است. تنظیمات اصلی در `src/data/customizer/settings.json` و فایل‌های پترن‌اند؛ فایل‌های اصلی را قبل از ذخیرهٔ تنظیم جدید نگه دارید.
- `npm run tokens:refresh` پس از تغییر تعریف متغیرها قرارداد ویرایشگر را بازتولید می‌کند. `npm run format:check` قالب را بررسی می‌کند؛ `npm run format` تغییرات گستردهٔ قالب می‌نویسد و باید پس از بررسی diff اجرا شود.

## اتصال بک‌اند و موارد باز

این بسته سرور، دیتابیس یا CMS ندارد. فرم مشاوره و RFQ فقط رویداد قابل اتصال تولید می‌کنند و در نبود adapter پیام غیرفعال‌بودن سرویس نشان می‌دهند. فیلتر و جستجوی کاتالوگ نتایج واقعی از API دریافت نمی‌کند. ۷۵ لینک جای‌خالی در صفحات ترکیب‌شده از نسخهٔ قبلی حفظ شده‌اند؛ مقصد مقاله‌ها، شبکه‌های اجتماعی، فایل دانلود و داده‌های نهایی به تصمیم صاحب پروژه نیاز دارد.

ورود در توسعه پیش‌نمایش است (OTP آزمایشی `123456`). ساخت عادی ورود واقعی را بدون تنظیم API فعال نمی‌کند؛ حالت `backend` adapter را فعال می‌کند، اما بدون meta توکن CSRF معتبر درخواست ارسال نمی‌شود. `.env.example` نمونهٔ بدون راز است. متغیرهای `VITE_` داخل مرورگر قرار می‌گیرند و محل نگهداری secrets نیستند. قرارداد دقیق پنج عملیات Auth و رویدادها در راهنمای HTML و `docs/BACKEND-INTEGRATION.md` آمده است.

## تحویل و بررسی‌ها

نسخهٔ قابل‌تحویل شامل سورس، تصاویر، فونت‌ها و lockfile است؛ پس از استخراج `npm ci` اجرا کنید. `node_modules`، cache، خروجی قدیمی، تاریخچهٔ Git و فایل‌های داخلی پیگیری همراه بسته نیستند. هیچ اتصال انتشار خودکار لازم نیست. گزارش آزمون‌های همین مأموریت و فهرست تک‌تک فایل‌ها در راهنمای HTML درج می‌شوند. گزارش‌های تاریخ‌دار قبلی صرفاً سابقهٔ فنی‌اند و اثبات اجرای آزمون در محیط جدید محسوب نمی‌شوند.

بررسی اختصاصی مرورگر قبلی (`scripts/check-browser.js`) به Chrome دارای CDP و preview بک‌اند نیاز دارد؛ با `SITE_URL` و `CDP_URL` قابل تنظیم است. نبود این اتصال به معنی موفق‌بودن آزمون نیست. پروژه lint، typecheck یا framework تست جداگانه تعریف نکرده و بررسی‌های معنی‌دار آن با اسکریپت‌های `check:*` انجام می‌شوند.

بازبینی ۲۸ اکتبر ۲۰۲۶: کنترل SVG علاوه بر لینک مستقیم اجرایی، تغییر `href` یا رویدادها از طریق انیمیشن SVG را نیز رد می‌کند؛ ارجاع عددی XML و نام‌های دارای namespace بررسی می‌شوند. انیمیشن بی‌خطر مانند تغییر opacity همچنان مجاز است. سرو محلی فایل‌های کلید و گواهی خصوصی با پسوندهای `.p12` و `.pfx` نیز مسدود است. این کنترل‌ها جای اعتبارسنجی آپلود و تنظیم امنیت سرور مقصد را نمی‌گیرند. مسیرهای انگلیسی `/en/` و عربی `/ar/` از همین قالب‌ها تولید می‌شوند؛ تغییر زبان در هر صفحه، همان صفحه را در زبان مقصد باز می‌کند. معماری، فونت‌ها و روش ادامهٔ کار در [docs/LOCALIZATION.md](docs/LOCALIZATION.md) ثبت شده‌اند.

## ادامهٔ توسعهٔ سه‌زبانه

نسخهٔ مرجع توسعه همین پوشه و همین مخزن `saeideeshghi/marpich-sanat-v4` است. برای دیدن نسخه‌ها پس از `npm run dev`، `/index.html`، `/en/index.html` و `/ar/index.html` را باز کنید. محتوای هر سه زبان از یک قالب می‌آید؛ ترجمه‌ها در `src/i18n` هستند و کپی مستقل از صفحه طراحی نکنید. گزارش این نسخه در [docs/RELEASE-4.1.0.md](docs/RELEASE-4.1.0.md) قرار دارد.
